# Contributing to doc2pdf

Thank you for your interest in contributing to **doc2pdf**! 🎉

## Ways to Contribute

1. **Reporting Bugs**: Open an issue describing the error, the document URL format, your browser version, and reproduction steps.
2. **Submitting Enhancements**: Open a feature request to discuss proposed functionality or UI improvements.
3. **Pull Requests**:
   - Fork the repository and create your feature branch: `git checkout -b feat/my-new-feature`.
   - Ensure all tests pass: `npm test`.
   - Commit your changes with clear messages (following Conventional Commits).
   - Push to your branch and submit a PR against `main`.

## Development Guidelines

- **Vanilla JavaScript**: Keep dependencies minimal to ensure lightning-fast execution and easy review.
- **Manifest V3 Compliance**: Respect separate contexts (`MAIN` world, `ISOLATED` world bridge, background service worker).
- **Zero External Telemetry**: Maintain strict user privacy standards.

## Code of Conduct

Please treat everyone with respect and kindness.
